# sabinshamsul.dev

Personal portfolio website for **Syahmi Shamsul**

## Features

- Linear-inspired design system: near-black surface ladder, hairline borders, one blue accent
- Dark / light mode: follows system preference, manual toggle saved to localStorage
- Inter for text, JetBrains Mono for dates, tags and figures, real bullet lists
- Recruiter fact sheet in the About section (status, target roles, education, location)
- Project cards open an in-page detail view with write-up, screenshots and an embedded live demo
- Fully responsive with an accessible mobile menu, skip link, focus rings and reduced-motion support

## Tech Stack

- HTML / CSS / JavaScript (single-page, no frameworks, no build step)
- CSS custom properties for theming
- Native `<dialog>` for project details
- Google Fonts (Inter, JetBrains Mono)
- Hosted on GitHub Pages

## Projects Showcased

Each project opens in an in-page detail view with a write-up, screenshots and an embedded live demo where one exists.

- **MediVision** - Emergency department patient flow platform with XGBoost triage (Final Year Project)
- **Bone Fracture Detection** - EfficientNetB0 with Grad-CAM, deployed on Hugging Face
- **RAG over AI-governance law** - Cited question answering with FAISS and Gemini
- **Loan Repayment Risk Prediction** - Random Forest credit-risk model
- **kadku** - Digital business card behind a single QR scan
- **Smart Monitoring for Houseplants** - ESP32 and Raspberry Pi IoT prototype
